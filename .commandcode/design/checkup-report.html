Critical Issues

Critical

1. Focus disappears everywhere

Keyboard users cannot see where they are. cursor: none !important removes native cursor, and :focus-visible only changes text color — no outline or ring.

globals.css, all components

Fix: /design interaction

Critical

2. Purple accent contrast failure

#5E0ED7 on #0a0a0f achieves ~2:1 — way below WCAG AA 4.5:1 minimum. Affects every CTA, label, hover state, and brand mark text.

Used in every component via text-[#5E0ED7]

Fix: /design recolor

Critical

3. Form has no accessible labels

Contact form uses placeholder as the only label. No <label> elements. Screen readers and users who tab into fields lose all context.

src/app/contact/page.tsx

Fix: Add visible <label> elements

Critical

4. Animations ignore reduced-motion

Wolf-breathe, moon-pulse, cta-glow, and all scroll reveals run regardless of prefers-reduced-motion. Only cursor magnetism is suppressed.

globals.css, all section components

Fix: /design motion — wrap in reduced-motion media query

Watch Items

  • iOS Safari input zoom — Contact form inputs at 14px trigger auto-zoom. Needs 16px min at narrow widths.
  • Touch targets undersized — Hamburger, close, and social icons are 36px (below 44px WCAG minimum).
  • Stat labels too small — 7px with 0.06em tracking is illegible on mobile.
  • No skip-to-content link — Keyboard users tab through navbar on every page load.

What's Working

  • Coherent four-tier dark surface system with clear depth
  • Distinctive wolf-themed animations (breathing, moon pulse, CTA glow)
  • Strong performance — static generation, capped particles, no external images
  • Contact form covers idle, sending, success, and error states
  • Decide composition drives toward one clear conversion action
  • Custom cursor with spring physics and magnetic text is polished
